# Yao Guai Kung Fu Website

Starter static website for GitHub Pages.

## Files

- `index.html` — homepage
- `style.css` — shared styling
- `script.js` — mobile menu and Kung Fu dropdown behavior
- `images/` — main and mini Yao Guai logos
- Additional HTML pages for About, Kung Fu styles, Classes, Gallery, Testimonials, and Contact

## GitHub Pages

1. Create or open your GitHub repository.
2. Upload all files and the `images` folder to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose your main branch and `/ (root)`.
7. Save.

The site uses only relative paths, so it works from a GitHub Pages project repository without changing the image or CSS links.
